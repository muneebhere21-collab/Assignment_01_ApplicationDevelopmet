# Contributing to EduTrack

Thank you for your interest in contributing to EduTrack! 

## Code of Conduct
Please ensure that your contributions align with our professional standards. Be respectful and constructive in your feedback and code reviews.

## How to Contribute
1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine.
3. **Create a branch** for your feature or bug fix (`git checkout -b feature/your-feature-name`).
4. **Make your changes** and test them thoroughly.
5. **Commit your changes** with clear and descriptive commit messages.
6. **Push the branch** to your GitHub repository.
7. **Submit a Pull Request** against the `main` branch.

## Development Setup
- Ensure you have the Flutter SDK installed (`>=3.0.0 <4.0.0`).
- Run `flutter pub get` to install all dependencies.
- Use `flutter analyze` and `dart format .` before submitting your PR to ensure code quality.

## Architecture Guidelines
- Follow the Clean Architecture pattern defined in the `lib/` directory.
- Ensure that UI logic, business logic, and network logic are kept in their respective directories (`screens/`, `controllers/`, `services/`).

Thank you for contributing!
